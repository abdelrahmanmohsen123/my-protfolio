الملخص المهني

مهندس برمجيات باك إند متخصص في لغة PHP، وإطار عمل Laravel، وتصميم معماريات واجهات البرمجة RESTful APIs، وتحسين أداء قواعد بيانات MySQL. خبرة واسعة في بناء الأنظمة الخلفية عالية الحمل، وتأمين الصلاحيات، وإدارة المهام المجدولة وقوائم الانتظار، وتحسين استعلامات قواعد البيانات المعقدة. سجل حافل بالإشراف والمساهمة في دورة التطوير الكاملة للأنظمة الإنتاجية في مجالات النقل واللوجستيات، الرياضة، والأسواق المالية والخدمية. خبرة عملية في التعامل مع خوادم Linux وإعداد خوادم الويب Apache و Nginx ومبادئ حاويات Docker.

المهارات التقنية

هندسة الباك إند (التخصص الأساسي): PHP، إطار عمل Laravel، تصميم واجهات RESTful APIs، أنظمة التوثيق والصلاحيات (Sanctum/Passport/RBAC)، منطق الأعمال المعقد، معالجة المهام الخلفية وقوائم الانتظار (Queues & Scheduled Jobs)، Eloquent ORM وتحسين الأداء، ربط بوابات الدفع والـ Webhooks.
قواعد البيانات وتحسين الأداء: MySQL، تصميم المخططات العلائقية (ERD)، تحسين استعلامات SQL، الفهرسة (Indexing)، سلامة المفاتيح، التخزين المؤقت Redis.
الواجهات ولوحات التحكم (ممارسة عملية): JavaScript (ES6+)، jQuery، قوالب Laravel Blade، Bootstrap (v4/v5)، HTML5 / CSS3.
الخوادم والأدوات: Git، GitHub، Bitbucket، Postman (اختبار ومجموعات الـ APIs)، خوادم Linux (Admin 1 / Bash)، إعداد Nginx و Apache، مبادئ حاويات Docker، Composer.
مجالات التوسع والتعلم المستمر: إدارة خوادم لينكس المتقدمة، هندسة الـ DevOps وخطوط الإنتاج CI/CD، أساسيات الحوسبة السحابية AWS، تحليل البيانات.
